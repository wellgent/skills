# Model Routing Convention

Routing sets thinking effort for brain work.
The model is whatever the runtime and its fleet config choose.

## Levels

- **Runtime default**: read-only lookups and query answers.
- **High**: any write to the brain, signal detection and background capture included.
- **Highest available**: deletions, merges, source-of-truth rewrites, and judge steps.
- A triage step that only filters candidates for a later step may run below its step's level.

## Rules

- Name effort levels, never vendor model names, in brain guidance.
- Set effort through the runtime's own controls, not through brain-local integration config.
- When the runtime cannot set effort separately, use its default settings.
